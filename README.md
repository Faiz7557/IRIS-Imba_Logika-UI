# IRIS Imba — UEC LOGIKA UI 2026

Proyek EduShield untuk babak penyisihan UEC LOGIKA UI 2026.

Prototype online: [EduShield](https://iris-imba-logika-ui.vercel.app).

Deployment Vercel terhubung ke repository ini dengan root directory `edushield/app`.

## Isi repository

- `edushield/`: prototype offline, kode analisis, data, dan hasil verifikasi.
- `paper/`: naskah dan script penyusunan paper.
- `deliverables/`: paket hasil untuk pengumpulan.

## Membuka prototype

Buka `edushield/app/index.html` di Chrome atau Edge. Prototype dapat berjalan tanpa server dan koneksi internet.

Petunjuk reproduksi riset dan verifikasi tersedia di [README EduShield](edushield/README.md).
